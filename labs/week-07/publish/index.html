Runnable integration

  1. Start the API: install and run npm run dev from source/api/.
  2. Start the frontend: install and run npm run dev from source/frontend/.
  3. Try the flow: create a request, inspect its details, update its status, and delete it.

API data is held in memory and resets when the API process restarts. Configure CORS and the frontend API URL with environment variables.
