# LAB 11 demonstration checklist

No recording has been submitted in this repository. Use this checklist when capturing the required demonstration.

1. Start SQLite-backed API and Vite client; show the dashboard loaded from `GET /api/requests`.
2. Filter requests, open a detail page, update a status, then create a request and show the new ID.
3. Visit `/api/health` and show the environment, uptime, SQLite driver, and table count.
4. Request an unknown API route and show the JSON 404; stop the API briefly to show the frontend's connection error.
5. Explain the service's SQL join and the production build/static serving path.

The GitHub Pages showcase is static and does not run the Express API or SQLite database. A live full-stack demonstration requires the API and a persistent database to be hosted separately or on a Node.js host.
