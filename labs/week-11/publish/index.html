Campus Service

A three-tier campus service-request application integrating a responsive React client, an Express JSON API, and a relational SQLite database.

Submission showcase · Tests pass
Hosting note: This GitHub Pages page is a static showcase. GitHub Pages cannot run the Express server or SQLite. The interactive app needs its API and persistent database deployed separately; the production Express app serves the built frontend when hosted on a Node.js service.

Frontend

React and Vite provide the dashboard, request filtering, details, status updates, and validated request creation.

API

Express exposes JSON request routes, a database-aware health endpoint, centralized errors, and production static-file serving.

Database

SQLite stores normalized users and requests with foreign keys, status constraints, indexes, and transactional creation.

Source includes the LAB 11 checkers, API tests, setup scripts, production build configuration, and run documentation.
