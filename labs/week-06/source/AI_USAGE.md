# AI_USAGE — LAB 06

บันทึกการใช้ AI ระหว่างทำงาน · **ใช้ AI ได้ แต่ต้องเป็นเจ้าของโค้ดที่ส่ง**

> ผู้สอนจะสุ่มถามจากโค้ดที่ส่ง — ถ้าอธิบายไม่ได้ คะแนนส่วนนั้นจะถูกทบทวน

---

## ครั้งที่ 1

**ถามอะไร**
ช่วยตรวจความพร้อมของ LAB06 เพื่อเผยแพร่ และทำให้ API ที่ยังมี TODO ทำงานครบ

**AI ตอบว่าอย่างไร (สรุปสั้น)**
ตรวจพบว่า API หลักผ่าน 23/23 แต่ error handler, PUT และ persistence ยังไม่ครบ จากนั้นช่วยเติมส่วนเหล่านี้และทำหน้าเอกสาร static สำหรับ GitHub Pages

**ใช้ส่วนไหน / แก้เองตรงไหน**
AI ช่วยแก้ route, controller, service, middleware, persistence และสร้างหน้า showcase; ผู้ส่งควรตรวจ diff และทดลองอธิบาย/ทดสอบโค้ดก่อนส่ง

**เข้าใจโค้ดที่ได้มาไหม** ☐ เข้าใจทั้งหมด ☐ เข้าใจบางส่วน ☑ ต้องทบทวนและยืนยันด้วยตนเอง
