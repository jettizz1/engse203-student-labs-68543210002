API Endpoints

GET/api/requests

ดูรายการทั้งหมด หรือกรองด้วย ?status=pending

GET/api/requests/:id

ดูรายละเอียดคำร้องหนึ่งรายการ · ไม่พบตอบ 404

POST/api/requests

สร้างคำร้องใหม่ · ตรวจ input และเริ่มสถานะเป็น pending · ตอบ 201

PUT/api/requests/:id

อัปเดตสถานะเป็น pending, in-progress หรือ completed

DELETE/api/requests/:id

ลบคำร้อง · สำเร็จตอบ 204

ตัวอย่างสร้างคำร้อง

ส่ง JSON ไปยัง POST /api/requests โดยใช้ Content-Type: application/json

{
  "requesterName": "ทดสอบ นักศึกษา",
  "requestType": "แจ้งซ่อม",
  "location": "อาคารวิศวกรรม ห้อง 301",
  "details": "เครื่องปรับอากาศในห้องไม่ทำงาน",
  "priority": "normal"
}
