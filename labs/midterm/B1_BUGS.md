## วิธีกรอก (อ่านก่อนเริ่ม)

กรอกให้ครบ **ทั้ง 6 บั๊ก** · แต่ละบั๊กเขียน 3 อย่างด้วย **คำของตัวเอง** (จะถูกสุ่มถามใน oral)

| คอลัมน์ | ใส่อะไร | ตัวอย่างสิ่งที่เขียน *(บั๊กสมมติ)* |
|---|---|---|
| **ไฟล์ : บรรทัด** | ไฟล์ที่แก้ + เลขบรรทัด | `Foo.jsx : 12` |
| **สาเหตุ** | **ทำไม** มันทำงานผิด (ไม่ใช่แค่ "พิมพ์ผิด") | "ใส่วงเล็บท้ายชื่อฟังก์ชัน เลยถูกเรียกทันทีตอน render" |

## บันทึกของฉัน — กรอกทั้ง 6 บั๊ก

| # | อาการ (ให้มาแล้ว) | ไฟล์ : บรรทัด|   สาเหตุ (ทำไมผิด) | แก้อย่างไร |
|---|---|---|---|---|
| 1 | Console เตือนสีเหลืองเรื่องรายการ (list) ที่แผงสรุป| summary panel.jsx :15|ลืมใส่ attribute key ในการลูปแสดงผลรายการผ่าน .map() ทำให้ React แจ้งเตือนเรื่องการระบุตัวตนของ DOM element |เพิ่ม key={item.id} หรือใช้ index เข้าไปในแท็กครอบของ .map() |
| 2 | ตัวเลข "เสร็จสิ้น" ในแผงสรุปไม่ตรงกับที่เห็นจริง |SummaryBoard.jsx : 28 |งื่อนไขการเช็ก string ในการนับจำนวนผิดพลาด เช่น เขียนเปรียบเทียบข้อความสถานะตัวพิมพ์เล็ก-ใหญ่ไม่ตรงกัน หรือสะกดชื่อสถานะผิด (item.status === 'COMPLETED' แทนที่จะเป็น 'completed')|แก้ไขตัวแปรเปรียบเทียบสถานะให้ตรงกับข้อมูลจริง เช่น เปลี่ยนเป็น item.status === 'completed'  |
| 3 | กดตัวกรองสถานะใด ๆ แล้วผลไม่เปลี่ยน (เหมือนกรองไม่ทำงาน) |RequestList.jsx : 42  |ฟังก์ชันกรองข้อมูลถูกเรียกใช้งานแต่ไม่มีการอัปเดต state ของตัวกรอง หรือคืนค่าการกรองผิด เช่น ลืมคืนค่าจากฟังก์ชัน .filter()  |แก้ไขให้มีการเรียก setFilterStatus(newStatus) หรือแก้ไขการคืนค่าใน .filter(item => ...) ให้ถูกต้อง |
| 4 | เปลี่ยน URL `REQ-101` → `REQ-102` แล้วข้อมูลไม่เปลี่ยน |RequestDetail.jsx : 18  |โค้ดที่ดึงข้อมูลใส่ useEffect โดยกำหนด dependency array เป็น [] ทำให้ดึงข้อมูลแค่ตอน render ครั้งแรกเท่านั้น และไม่ดึงใหม่เมื่อ id จาก URL เปลี่ยน  |ใส่ค่า id หรือ parameter จาก URL ลงใน dependency array เช่น useEffect(() => { ... }, [id])  |
| 5 | กด "ลบ" แล้วการ์ดหาย แต่ตัวเลขในแผงสรุปไม่ลด |App.jsx : 41 |การลบข้อมูลทำเพียงแค่ลบออกจาก state ภายในคอมโพเนนต์ย่อย แต่ไม่ได้อัปเดต state หลัก (Global / Parent state) ที่นำไปใช้คำนวณแผงสรุป  |เรียกฟังก์ชันอัปเดต state ของรายการหลักในคอมโพเนนต์แม่ด้วย เช่น setRequests(prev => prev.filter(...))  |
| 6 | กด "ลบ" แล้วหน้าพัง/ว่างเปล่า |RequestCard.jsx : 50  |มีการเข้าถึง property ของวัตถุที่โดนลบไปแล้วหรือกลายเป็น null / undefined (Cannot read property of undefined)  |เพิ่มการเช็กความมีอยู่ของข้อมูล (Optional Chaining) เช่น data?.id หรือใส่เงื่อนไขป้องกันการ render หากข้อมูลเป็น null  |
